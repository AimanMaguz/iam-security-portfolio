# IAM Security Portfolio

Hands-on identity and access management security projects, built to 
demonstrate practical skills across cloud IAM, federation, privileged 
access management, identity governance, and Zero Trust architecture.

Background: Senior Systems Administrator with production experience in 
SSO, Microsoft Entra ID, Conditional Access, and Intune, now focused on 
IAM security engineering.
